# Orrery v0.11.1 — Desktop update fix / 자체 업데이트 수정

## Install once manually / 이번에는 한 번 수동 설치

**v0.10.0 and v0.11.0 cannot reliably install this fix through their existing updater.** Download the ZIP for your computer below, quit Orrery, extract the archive, and replace the entire `Orrery.app` in Applications (macOS) or the entire Orrery folder (Windows). Keep the existing user-data and AWS configuration folders. Do not merge individual files or replace an app while it is running.

**v0.10.0·v0.11.0에서는 기존 updater로 이 수정 버전을 설치할 수 없습니다.** 아래 ZIP을 받은 뒤 Orrery를 종료하고 압축을 풀어 macOS는 응용 프로그램의 `Orrery.app` 전체, Windows는 Orrery 폴더 전체를 교체하세요. 사용자 데이터와 AWS 설정은 앱 외부에 있으므로 유지합니다. 실행 중인 앱이나 개별 파일만 덮어쓰지 마세요.

## Fixed / 수정

- Fixes `Invalid package …/app.asar` during update preparation in Electron. The updater previously treated the incoming ASAR file as a virtual directory while writing it.
- Uses Electron's native `original-fs` for update extraction, package validation, and transaction cleanup. Normal ASAR support stays enabled for the running app.
- Preserves ZIP path/link restrictions, SHA-256/size checks, version/OS/CPU validation, and macOS signature checks. No AWS permissions or resource operations are changed.
- 업데이트 준비 중 `app.asar` 쓰기에 실패하던 원인을 수정했습니다. 업데이터의 파일 작업만 실제 디스크 API로 처리하며, 실행 중인 앱의 ASAR 읽기는 유지합니다.

## Verification / 검증 범위

- 297 existing tests plus a real Electron regression test; typecheck and production packaging for macOS ARM, macOS Intel, and Windows x64.
- The regression first reproduced the same failure in Electron, then verified ASAR byte preservation, metadata/symlink rejection, cancellation cleanup, current-app preservation, and global ASAR support after the fix.
- All three release ZIPs were prepared and validated in real Electron on macOS, including metadata and macOS signatures. This does not claim native Windows execution or an actual installed-app replacement.
- Windows native installation/recovery and real release-to-release replacement remain unverified. Existing moderate dependency audit findings and OS signing/notarization limitations are unchanged.

English / 한국어 language selection from v0.11.0 is included.

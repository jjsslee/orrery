# Orrery v0.5.0

End user에서 시작하는 요청·응답 경로 시뮬레이션을 추가했습니다. 상단 **요청 흐름**에서 자원 또는 URL을 선택하고 End user를 누르면 요청 점과 응답 점이 선을 따라 이동합니다.

- CloudFront→S3와 API Gateway→Lambda의 설정상 왕복 경로, 캐시 적중 가정, FE 응답 후 별도 API 호출 시나리오를 지원합니다.
- 재생·일시정지·구간 이동·속도·재생 위치 조절을 제공합니다.
- AppSync·DB·큐 등 인접 자원도 함께 표시합니다. AppSync resolver, Lambda 내부 실행, ALB listener 등 확인되지 않은 구간에서는 멈춥니다.
- CORS는 FE–API 후보 탐색의 내부 근거이며 상세에서만 설명합니다. 실제 FE 호출이나 응답 성공을 보장하지 않습니다.
- 계정·리전·인증 소스별 수집 결과를 사용하며 범위가 바뀌면 재생을 초기화합니다. API Gateway V2 라우트를 추가 수집하므로 해당 읽기 권한이 필요합니다.
- v0.4.0 이후 데스크톱 앱이 Electron 독립 창으로 전환되었습니다. 브라우저 탭을 따로 열지 않으며 macOS는 칩별 패키지를 제공합니다. @fastify/static도 10.1.7로 업데이트됐습니다.

## 다운로드

- Apple Silicon(M1 이후): `Orrery-macos-arm64.zip`
- Intel Mac: `Orrery-macos-x64.zip`
- Windows x64: `Orrery-windows-x64.zip`을 모두 풀고 `Orrery.exe` 실행

macOS 앱은 ad-hoc 서명입니다. Apple Developer ID 서명·공증과 Windows 코드 서명은 제공하지 않습니다. 이전 버전을 종료한 뒤 새 앱을 실행하세요.

## 검증과 한계

서버 88개·웹 66개, 총 154개 테스트와 전체 typecheck, production build를 통과했습니다. fixture 브라우저에서 요청·응답 재생, AppSync 중단, scope 변경 초기화, 캐시 적중, 숨김 중단, reduced-motion 및 데스크톱·모바일 화면을 확인했습니다.

세 플랫폼 ZIP 무결성, macOS ARM·Intel ad-hoc 서명, Windows x64 PE 형식, 각 패키지의 버전과 요청 흐름 UI 포함을 확인했습니다. Electron utility process에서 macOS ARM 패키지의 내장 서버를 실행해 health(`0.5.0+20261026T065510Z`)·읽기 전용 상태·내장 웹 자산을 확인했습니다. `SHA256SUMS.txt`로 다운로드 파일을 검증할 수 있습니다.

이 기능은 설정 기반 시뮬레이션이며 실제 서비스로 요청을 보내지 않습니다. 실계정의 신규 경로 대조, Windows·Intel Mac 실제 실행은 미검증입니다.

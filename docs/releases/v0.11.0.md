# Orrery v0.11.0 — English & 한국어

## English

- Choose **English** or **한국어** in the top bar. The interface changes immediately and remembers your choice on this device.
- Desktop menus and newly opened update prompts follow the selected language.
- Keep your current view, filters, selected resources, and monitoring time range when switching languages. Switching languages does not trigger an AWS refresh.
- Resource names, ARNs, tag keys/values, saved selection names, and original AWS messages remain unchanged.
- Translate metric titles and resource properties, including **Errors** and **Oldest message age**, and prevent time/count patterns from partially translating unrelated labels.

## 한국어

- 상단에서 **한국어 / English**를 선택하면 즉시 반영되고 다음 실행에도 유지됩니다.
- 데스크톱 메뉴와 새로 표시되는 업데이트 안내에도 선택한 언어가 적용됩니다.
- 언어를 바꿔도 현재 화면·필터·선택 자원·모니터링 기간을 유지하며, AWS를 다시 조회하지 않습니다.
- 자원 이름·ARN·태그·저장 구성 이름·AWS 원문 메시지는 원문을 유지합니다.
- 지표명과 자원 속성의 번역을 추가하고, `오류 수`·`최장 대기 시간` 누락과 시간·개수 패턴의 잘못된 부분 번역을 수정했습니다.

## Downloads / 다운로드

## Verification / 검증 범위

- 297 tests (server 149 / web 107 / desktop 41), typecheck, and production build passed. The existing large-graph pagination test intermittently failed during validation and passed on the final full rerun without changes to its code or assertions.
- All three packages were checked through the updater's archive preparation path, including version/platform/CPU metadata and macOS ad-hoc signatures. SHA-256 checksums are attached as `SHA256SUMS`.
- English fixture screens were scanned for untranslated Korean across topology, resources, monitoring, and cleanup candidates. Language switching preserved selections and issued no extra data queries. Native macOS menu language/persistence and renderer isolation were verified with temporary settings and a local fixture; AWS was not queried.
- Windows native execution and real release-to-release app replacement remain unverified. OS signing/notarization status is unchanged; macOS uses ad-hoc signing and Windows is unsigned.
- The locked runtime dependencies retain 3 moderate audit findings through `@fastify/static` → `glob` / `minimatch` (0 high/critical). This feature release does not upgrade dependencies. The current static-file registration uses a fixed startup glob, not a user-supplied pattern; this scope check is not a general claim that the dependencies are vulnerability-free.

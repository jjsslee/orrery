# 다국어 지원

[문서 목록](README.md) · [사용 가이드](usage.ko.md)

화면 상단에서 `한국어`와 `English`를 선택한다. 선택은 이 기기에 저장하며 즉시 반영한다. 최초 언어는 브라우저의 언어를 사용한다(`ko*`는 한국어, 그 외 영어). 데스크톱 메뉴는 저장된 설정이 없으면 운영체제 언어를 사용하고, 화면이 연결되면 화면 설정에 맞춘다.

## 번역 경계

- `shared/src/i18n.ts`: 언어 판별, 한국어 원문 키 기반 번역과 인자 보간.
- `shared/src/translations/en.ts`: 영어 카탈로그. `{0}`, `{1}` 인자는 원문과 개수·번호를 맞춘다.
- `web/src/i18n.ts`: React 구독과 `orrery.language` localStorage 저장. `useLanguage()`로 변경을 구독하고 `uiText('문구')` 또는 tagged template로 화면을 번역한다.
- `components/format.ts`: 날짜·숫자·상대 시간의 locale 적용. 일반 속성 문자열은 유지하고, 명시한 시스템 범주 속성의 값만 번역한다.
- `desktop/src/language.ts`: userData의 `language.json`에 허용된 언어만 저장한다. 임시 파일 작성 후 rename하며 main에서 저장을 직렬화한다.

원본 자원·상태 enum·속성 키·API 식별자를 번역된 문자열로 바꾸지 않는다. 자원 이름, ARN, 태그의 키와 값, 저장 그룹 이름, AWS 원문 오류는 원문을 유지한다. 제어되는 시스템 메시지와 유형·상태·지표 이름만 표시 시 번역한다. 비동기 작업의 상태에는 원문을 저장하고 렌더링 시 번역하여 진행 중 언어 변경도 반영한다. 번역문을 필터·조건 비교의 식별자로 사용하지 않는다.

서버에서 이미 보간한 시스템 메시지는 카탈로그의 원문 패턴으로 번역한다. 원문 키와 매칭되지 않는 외부 메시지는 유지한다. 새 시스템 메시지를 추가하면 실제 동적 결과도 두 언어로 확인한다.

## 데스크톱 연동

화면은 기존 인증 API에 `POST /api/preferences/language` (`{"language":"en"}` 또는 `{"language":"ko"}`)를 보낸다. 기존 loopback host/origin·bearer token 검사를 유지하고 요청 크기는 128 bytes로 제한한다. 서버는 기존 utility process parentPort로 main에 전달한다. main은 언어를 다시 검증하고 메뉴를 재구성하며, 업데이트 진행 중에는 메뉴의 비활성 상태를 유지한다. preload나 renderer Node 권한은 추가하지 않는다.

언어 변경은 AWS 조회, 앱 상태 초기화, 화면 remount를 실행하지 않는다. 웹 저장이 제한되면 현재 세션의 언어 전환은 가능하지만 다음 실행에 유지되지 않을 수 있다. 이미 열린 native 대화상자는 다음에 표시할 때 새 언어를 적용한다.

## 확인 방법

`npm run typecheck`, `npm test`, `npm run build`를 실행한다. 번역 인자 보존, 웹 저장·초기 언어·사용자 값 유지, 인증된 언어 API와 잘못된 요청 거부, 데스크톱 저장·업데이트 메뉴 언어 변경을 회귀 검증한다.

실제 UI는 AWS 연결 없이 로컬 API fixture로 확인한다. 두 언어에서 topology·유형별·모니터링·정리 후보를 확인하고, 전환 전후 선택·필터·기간과 API 호출 수를 비교한다. 번역한 문자열이 길어져도 좁은 화면에서 언어 선택을 사용할 수 있어야 한다. Windows native 메뉴의 실제 표시는 별도 실기기 검증이 필요하다.

### 2026-11-04 v0.11.0 구현 검증

- 서버 149개, 웹 107개, 데스크톱 41개 테스트 통과. 기존 대형 그래프 페이지 테스트는 전체 실행 중 간헐 실패했으며, 코드·assertion 변경 없이 최종 전체 재실행에서 통과했다.
- 영어 fixture의 네 가지 주요 화면에서 사용자 데이터를 제외한 한글 잔여를 DOM 텍스트로 검사했다. `오류 수`와 `최장 대기 시간`의 번역, 수치 자리와 일반 문구의 구분은 별도 회귀 테스트로 고정했다. 표시 문구·서버 지표명·수집 속성 키의 카탈로그 누락도 검사한다.
- 화면 언어 변경 후 검색어·상세 자원 선택·모니터링 대상 3개·24시간 범위 유지, 추가 데이터 API 호출 없음, 새로고침 후 언어 유지 확인. 검증용 자원 이름과 공개 화면에는 구분되는 가상 이름을 사용한다. 한국어 자원 이름·태그·설명 보존은 별도 테스트로 확인했다.
- macOS의 실제 Electron에서 저장 언어 복원, 영문·한글 메뉴 전환, 연속 변경의 저장 순서와 renderer 격리 유지 확인. Windows native 메뉴 실기동은 미검증이다. AWS는 호출하지 않았다.

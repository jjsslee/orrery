## 적용 범위

이전 감사에서 확인한 잘못된 소속·관계 추정과 실패 은폐를 수정했다. 이번 구현 작업 중 AWS API는 호출하지 않았다. 실제 AWS 생성·수정·삭제는 전혀 수행하지 않았으며 모든 추가 SDK 작업은 기존 읽기 전용 명시적 허용 목록과 가드를 사용한다.

| 감사 문제 | 반영 결과 |
|---|---|
| ECS host/bridge 위치 누락 | 실행 태스크→컨테이너 인스턴스→EC2 VPC 추적, 실행 호스트 연결. 불완전 조회·실행 수 0은 미확인, 복수 VPC는 임의 단일 배치하지 않음 |
| ECS 일괄 실패 전파 | 누락·실패 서비스 개별 재조회. 권한 외 오류도 포함하는 상세 조회 실패로 표시 |
| SG VPC 누락 | 원본 VpcId로 소속 지정 |
| 위치 범위 혼동 | 글로벌/리전·논리/위치 미확인·복수 범위 분리, 누락 부모 ID 보존과 경고 |
| 부분 수집 실패 | 성공한 결과는 유지하고 실패를 수집 누락·주의에 노출. 네트워크 개별 API 실패로 전체 결과가 사라지지 않음 |
| NAT 경로 오표기 | 실제 IPv4/IPv6/Prefix List 목적지와 상태, NAT·IGW·TGW 경로 표시. blackhole은 위험 상태 |
| IP 타깃 및 TG 접힘 | 등록 IP·포트·헬스 노드 추가. 실제 호스트/VPC와 동일시하지 않음. 접힐 때 최악 상태 보존, 해석 대상이 없는 TG 유지 |
| 이름 기반 오연결 | 외부 ARN/ECR/SQS URL 범위 보존, 모호한 평문 이름은 연결하지 않음. 자유 형식 참조는 ‘설정 참조’로 표시 |
| 상세 관계 누락 | 알려진 custom DNS·실제 listener ARN 해석, instance profile의 실제 Roles 조회, EKS 관리 노드 그룹→ASG 연결, EventBridge 대상 페이지 순회 |
| 실측처럼 보이는 선 | 노드 활동량을 선의 트래픽으로 변환하지 않음. 조회 전 idle 점선 움직임 제거. 비활성·위험 관계의 흐름 비활성화 |
| 추정 위치 확정 | ASG 설정 서브넷 활용, RDS/ElastiCache 다중 후보 임의 선택 제거, Multi-AZ RDS VPC 수준 배치, Lambda/EKS 연결 설정의 의미 설명 |
| 상태·필터·갱신 | 미조회 Lambda/Step Functions/API stage/S3 설정을 정상·없음으로 단정하지 않음. 필터에서도 부모 유지, 부모 변경 시 재배치, 서로 다른 관계 조건을 별도 유지 |

도식 가이드와 README를 함께 갱신했다. 그래프 캐시는 graph-v8로 변경해 이전 오표현이 남은 캐시를 재사용하지 않는다. 기존 ARN 복사 권한·실패 안내 수정도 작업 폴더에 보존돼 있다.

## 검증

- 수정 전 회귀 테스트에서 ECS·SG·NAT·부분 실패·소속·참조·접힘 오류 확인 후 수정했다.
- 최종 전체 테스트 210개 통과: server 127, web 80, desktop 3. 실패 0.
- shared/server/web/desktop TypeScript 검사 통과.
- 웹 프로덕션 빌드 통과, git diff --check 통과.
- 실제 SDK의 읽기 전용 허용 목록·미들웨어 검증 포함. 테스트의 AWS 응답은 더미 fixture이며 실제 네트워크를 호출하지 않는다.
- 기존 테스트의 자유 형식 참조→접근/발행 단정과 부모 삭제 기대값은 새 의미에 맞춰 변경했다. 인증서·WAF 연결 같은 기존 유효한 관계 검증은 유지했다.

## 남은 범위와 배포 상태

- 실제 파르나스 계정 재수집, 브라우저/설치 앱 시각 검증은 이번 수정 후 수행하지 않았다. 감사 때 확인한 실제 자원 수를 수정 후 실계정 검증 수치로 재사용하지 않는다.
- v0.8.1 릴리즈용 설치 패키지로 배포한다. 사용 중인 설치 앱은 새 패키지로 교체해야 반영된다. 실제 계정 화면·설치 앱 실기동·Windows 실행 검증은 별도 미실행이다.
- 추가 구현: ALB 전체 listener rule 조건/우선순위/동작/가중치, CloudFront behavior별 오리진과 failover 순서, Cloud Map 등록 대상, Route 53 private zone VPC, Lambda EFS access point와 ECR 이미지, VPC Endpoint 서비스/서브넷/DNS/정책/라우팅, OpenSearch Serverless Endpoint와 네트워크·데이터 정책 관계를 수집한다. 페이지가 나뉜 응답도 수집하며 조회 실패는 부분 수집으로 표시한다.
- 자원 상세가 없는 연결 대상은 원본 식별자를 보존한 구성 대상 노드로 남긴다. OpenSearch는 현재 지원 서비스인 Serverless 범위이며, IAM·NACL·애플리케이션을 합친 종합 접근성 판정이나 실제 패킷 추적은 수행하지 않는다.
- 단일 노드로 여러 AZ/서브넷을 요약한다. 정확한 위치를 확인하지 못하면 VPC 수준 또는 미확인 영역으로 표시한다.
- 설정 참조는 실제 사용·호출·권한·통신 성공의 증거가 아니다. SG 규칙 역시 전체 접근 가능성 판정이 아니다.

## 추가 검증

ALB 규칙 페이지 순회·가중치, CloudFront 경로, private zone의 다른 리전 VPC, Cloud Map 페이지 순회, Lambda EFS/ECR 매핑과 다운로드 URL 비저장, OpenSearch 네트워크/데이터 정책과 Endpoint, 추가 조회 권한 실패를 더미 SDK 응답으로 검증했다. 실제 AWS 재수집은 실행하지 않았다.

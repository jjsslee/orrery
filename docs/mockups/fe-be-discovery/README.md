# FE–BE 탐색 UI 시안

이전 시안이다. 최신 사용자 요청은 [End user 요청·응답 흐름](../request-journey/index.html) 시안에 반영했다.

사용자 선택 전 비교용 독립 HTML이다. production UI나 AWS API와 연결하지 않는다. 모든 계정·도메인·자원 이름은 예시 데이터다.

- **A 지도에서 바로 펼치기 (추천):** 선택 FE의 점선/후보 끝점을 눌러 현재 지도에 BE를 펼친다. 연결 근거는 필요할 때 연다.
- **B 후보 패널에서 비교:** 오른쪽에서 API 후보와 근거를 비교하고 지도에 해당 BE를 펼친다.
- **C 서비스 경로에 집중:** 주변 자원을 접어 해당 FE와 BE를 별도 경로처럼 탐색한다.

`index.html`은 외부 dependency 없이 브라우저에서 직접 열 수 있다. 미리보기 서버는 다음 명령으로 실행한다.

```sh
python3 -m http.server 4831 --bind 127.0.0.1 --directory docs/mockups/fe-be-discovery
```

상단 A/B/C, FE 노드, 점선, API 후보, 연결 근거, 선택 해제, 하단 상태 선택, 다크/라이트 전환이 동작한다. 작은 화면에서는 지도 영역을 가로로 스크롤한다. 실제 구현의 자동 배치·자원 검색·프로필 변경을 재현하는 시안은 아니다.

검증: 1440px에서 세 안의 FE 선택→BE 펼침, 820/390px에서 문서 가로 넘침 없음, 다크/라이트 표시와 다른 API 후보 선택을 확인했다. 단계별 스크린샷은 같은 폴더에 저장했다. 최종 선택은 대화에서 받으며 브라우저 선택은 저장하지 않는다.

커밋은 사용자의 전체 구현 종료 지시 이후 한 번에 진행한다. 이 시안을 만들면서 commit/push/배포는 실행하지 않았다.

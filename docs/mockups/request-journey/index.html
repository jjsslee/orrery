분석 근거와 시안 범위

이 시안은 CF/S3에서 FE 파일을 받은 브라우저가 별도 API Gateway를 호출하고, Lambda 응답을 받는 예시입니다. FE–BE 후보는 내부적으로 CORS·코드·로그 등의 근거로 찾을 수 있습니다. 기본 화면에서는 이 분석 용어를 강조하지 않습니다. 설정만으로 실제 실행 경로를 보장할 수 없으며, 미확인 구간과 실제 관측은 구현 시 구분합니다. 이번 시안은 HTML/JS 파일들을 하나의 화면 수신 과정으로 묶었고, DB·외부 API 호출은 가정하지 않았습니다.
